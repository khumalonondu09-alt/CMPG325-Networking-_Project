## Project Overview

This project involves the design, implementation, testing, and documentation of a computer network for **Iketsetseng Private School (Mahikeng)** using Cisco Packet Tracer.

The network is designed to provide appropriate wired and wireless connectivity, network services, secure wireless access, and connectivity between the required network devices while making use of the allocated IPv4 addressing block.

## Assigned Networking Challenge

**Assigned Challenge: Secure Wireless Access and Additional Wireless Coverage**

The implementation addresses the wireless networking requirements by:

- Configuring secure wireless access using **WPA2-PSK**.
- Providing wireless connectivity for school users.
- Implementing an additional access point to extend wireless coverage to the requested additional floor/area.
- Testing wireless connectivity and communication with required network resources.

## Addressing

The project uses the allocated IPv4 address block:

`192.168.21.0/24`

The address space is subnetted to support the required network segments, including staff, students/labs, servers, wireless devices, and network management.

The planned network includes:

- Router and switching infrastructure
- Staff network
- Student/Lab network
- Server network
- Wireless network
- Network management segment
- DHCP and local network services
- WPA2-PSK wireless security

The implemented network will be tested to verify:

- Correct VLAN configuration
- Correct IP addressing
- DHCP operation
- Wireless connectivity
